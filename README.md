# SpringBoot 실습 저장소

이 저장소 하나를 **학기 끝까지** 쓴다. 매주 블로그 프로젝트를 여기에 얹어 나가면 된다.
push 할 때마다 **그 시점까지 배운 범위**가 자동으로 채점된다.

---

## 처음 한 번만 하는 설정

### 1. 저장소 만들기

위쪽 초록색 **`Use this template`** → **`Create a new repository`**

| 항목 | 값 |
|---|---|
| Owner | **daelim-spring-2026** (본인 계정 아님) |
| Repository name | **`sb-<학번>`** 예) `sb-20231234` |
| 공개 범위 | Public |

> 저장소 이름을 규칙대로 지어야 채점 현황에 잡힌다.

### 2. 내려받기

IntelliJ → `Get from VCS` → 방금 만든 저장소 주소

### 3. 지금까지 만든 블로그 코드 옮기기

3주차부터 만들어 온 프로젝트에서 아래를 복사해 넣는다.

```
src/main/java/...        → src/main/java/com/example/blog/
src/main/resources/...   → src/main/resources/
```

**패키지는 반드시 `com.example.blog` 여야 한다.**
다르면 IntelliJ 에서 패키지를 우클릭 → `Refactor` → `Rename` 으로 바꾼다.
채점 테스트가 이 패키지를 기준으로 동작한다.

### 4. push

```bash
git add .
git commit -m "블로그 프로젝트 옮김"
git push
```

---

## 그다음부터

**코드 고치고 push 하면 끝이다.** 다른 건 없다.

---

## 내 점수 보기

저장소 위쪽 **`Actions`** 탭 → 가장 최근 실행 클릭

이런 표가 나온다.

| 주차 | 통과 | 상태 |
|---|---|---|
| 3주차 | 1 / 1 | ✅ |
| 4주차 | 2 / 4 | ⚠️ |

아래에 항목별 결과와 **왜 실패했는지**가 같이 나온다.

```
[4주차] DELETE /api/articles/{id} 로 삭제하면 목록에서 사라진다
   ❌ 실패 — Status expected:<200> but was:<404>
```

## 알아둘 것

**채점 테스트는 이 저장소에 없다.**
push 할 때마다 최신 테스트를 받아와서 돌린다. 내려받아 열어볼 필요도, 건드릴 필요도 없다.

**내가 만든 테스트는 점수에 안 들어간다.**
`com.example.blog.grader.*` 만 채점 대상이다. 직접 만든 테스트는 자유롭게 써도 된다.

**지난 주차도 계속 채점된다.**
5주차 작업을 하다 3주차 API 를 망가뜨리면 바로 표에 뜬다. 그러라고 있는 것이다.

**빨간 X 가 떠도 감점이 아니다.**
진도를 같이 확인하려고 돌리는 것이다. 막히면 그대로 두고 질문하면 된다.
